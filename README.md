## 🚀 Instalación y Uso

### Prerrequisitos
```bash
Python 3.7+
Flask
```

### Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/NotExer/portfolio.git
cd portfolio
```

2. Crea un entorno virtual:
```bash
python -m venv venv
source venv/bin/activate  # En Windows: venv\Scripts\activate
```

3. Instala las dependencias:
```bash
pip install flask
```

4. Ejecuta la aplicación:
```bash
python app.py
```

5. Abre tu navegador en:
```
http://localhost:5000
```
